GSheet Column Reference

Full 26-column schema mapping (A-Z)
A0
Date Event date. Renders in footer-left & drives Tonight/Today tag.
B1
Day Day name fallback (e.g. EVERY MONDAY) in footer-left.
C2
Event Type Categorization (Rugby, Karaoke, Quiz). Drives badges & fallback styles.
D3
Event Name Primary slide title. Font-size autofits to prevent line wrapping.
E4
Details Main descriptive text area. Supports Shift+Enter line breaks.
F5
Billboard Text Custom short description used specifically for LED Billboard.
G6
Start Time Start time (e.g. 7:30 PM). Renders as a pill in footer-center.
H7
Price Price or special entry terms. Renders as a pulsing red footer pill.
I8
Location Location filter setting or specific venue area.
J9
Slide Footer Small disclaimer/footer text at the bottom-center.
K10
Slide Type Layout templates (e.g. Event, Promo, MENU, SOCIAL LINK).
L11
Hidden Notes Internal admin logs. Checked for "TBC" to auto-skip slides.
M12
Accent Hex Colour Custom hex code (e.g., #FFD700) to override theme colors.
N13
Countdown Finish Target timestamp used for visual countdown clock templates.
O14
Feature QR Main QR Code URL. Renders in the footer-right section.
P15
Footer QR Secondary / fallback QR Code URL in the footer.
Q16
Hyperlink Alternative website URL converted to footer QR code.
R17
Slide Duration Active slide display time in seconds (default: 30s).
S18
Slide Background Image filename or Hex Color to set slide background.
T19
Foreground Image Fullscreen overlay poster path (ignores central text).
U20
Bubble Text Text for floating promotional badge (e.g. SELLING FAST).
V21
Lock Slide Locks slide visibility to remain in screen rotation permanently.
W22
Lock Day Constrains visibility of slide to specific day only.
X23
Lock Time Constrains visibility of slide to specific hour range.
Y24
Transition Slide load animation style (e.g., Fade, ScrollDown, PanDown).
Z25
Zoom Background image scale zoom factor (e.g., 1.3).
